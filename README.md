# MyOpenClaw - 个人AI助理工作空间

这是一个基于OpenClaw平台的个人AI助理工作空间配置仓库。包含完整的助理身份定义、工作流规则、安全策略和进化历史。

## 📁 项目结构

```
MyOpenClaw/
├── AGENTS.md          # 工作空间规则和安全策略
├── SOUL.md            # 助理核心身份定义
├── IDENTITY.md        # 助理详细身份信息
├── USER.md            # 用户信息和工作偏好
├── TOOLS.md           # 工具使用指南
├── HEARTBEAT.md       # 心跳检查配置
├── MEMORY.md          # 长期记忆（不提交，包含敏感信息）
├── .gitignore         # Git忽略规则
├── README.md          # 项目说明
├── evolution-drafts/  # 进化提案
│   └── approved/      # 已批准的进化提案
├── skills/            # 技能目录（结构占位）
├── reports/           # 报告输出目录（结构占位）
│   ├── daily/         # 每日报告
│   ├── tasks/         # 任务产出
│   ├── boss/          # 领导分析
│   ├── trends/        # 趋势研究
│   └── memory/        # 知识提取
└── memory/            # 日常记忆记录（不提交）
```

## 🎯 核心功能

### 1. 助理身份系统
- **小A** 🦞：赵新奎的私人助理
- **定位**：信息猎手型AI，主动收集、分析、思考、建议
- **原则**：主动出击，带着观点来，简洁有力，严谨可靠

### 2. 日报系统
- **政策日报**：每天9:20，24小时政策热点+解读
- **国际形势日报**：每天9:25，24小时国际形势+解读
- **软硬件日报**：每天9:30，24小时软硬件热点+解读
- **银行零售日报**：每天9:45，零售获客/财富管理/生态同业+解读
- **AI日报**：每天10:00，大模型/智能体/产品发布/投资并购+解读
- **股市日报**：每天15:30，A股走势总结+下一交易日预测
- **投资日报**：每天17:30，国内投资领域当日情况+下一交易日关注重点

### 3. 安全策略
- **权限控制**：Owner最高权限，敏感操作需明确授权
- **反信息泄露**：不泄露个人信息、使用习惯、内部记录
- **技能保护**：安装前完整审查SKILL.md，拒绝恶意行为
- **运行时安全**：破坏性操作需确认，优先使用安全命令

## 🔧 技术特性

### 进化系统
- **Hermes-Evolution**：基于实际任务经验的持续进化
- **错误处理优化**：Web Fetch错误分类处理，错误率从25%降至5%以下
- **主动学习**：从错误中学习，优化工作流

### 工具集成
- **浏览器自动化**：优先使用autoglm-browser-agent
- **图像识别**：优先使用autoglm-image-recognition
- **网络搜索**：使用autoglm-websearch
- **飞书集成**：完整的日历、任务、文档、IM集成

## 📋 使用说明

### 快速开始
1. 克隆本仓库到本地工作空间
2. 配置OpenClaw环境
3. 根据需要修改配置文件
4. 启动AutoClaw助理

### 配置文件说明
- **AGENTS.md**：核心行为规则，修改前请充分理解影响
- **USER.md**：用户个人信息和工作偏好
- **TOOLS.md**：工具使用指南和环境配置
- **evolution-drafts/**：进化历史，记录系统改进过程

### 安全注意事项
1. **不要提交**：MEMORY.md、个人认证文件、临时文件
2. **定期审查**：技能安装前必须完整审查SKILL.md
3. **备份重要**：重要更改前必须备份，便于回滚
4. **权限分离**：生产环境和开发环境配置分离
